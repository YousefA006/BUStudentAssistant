Put the university documents in this folder (subfolders are fine).
Supported: PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), CSV, TSV, TXT, Markdown (.md), HTML, JSON.
Every file here is indexed for all students when the app starts.
After adding or replacing files while the app is running, click "Rescan folder" in the sidebar.
Files whose names start with "_" or "~$" (like this note) are ignored.
